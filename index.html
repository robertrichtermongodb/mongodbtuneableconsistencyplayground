Welcome

This simulator helps you understand how MongoDB read and write concerns shape data flow in a replica set. The goal is to make these guarantees tangible.

Note: MongoDB is fully consistent by default, despite the common misconception that it is eventually consistent only. It also offers powerful ways to tune consistency properties to your application's needs.

How to use: Fire a write (e.g. "New doc with ID 1"), then experiment with different read concerns and read preferences to see what each brings back. You can also inject faults — click nodes to toggle health, links to partition — and observe how consistency changes.
